Explore how deposits and allocations grow over a fixed horizon. Each run draws market paths for an uncertainty cone, then compares Low / Med / High savings (0.5× / 1× / 1.5× contribution amounts) and optionally maps a coarse allocation grid. Results are exploratory — not an optimized portfolio.

Weight grid uses a 20% step (up to 48 mixes) with fewer paths per point so the cloud stays coarse. Median ending balance drives the weight tornado.
